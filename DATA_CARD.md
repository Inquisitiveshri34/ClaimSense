# ClaimSense — Data Card

> One frozen, anonymised, deduplicated set of health-insurance ombudsman decisions from India, the UK and Ireland, split by decision date. The input is each case's **facts** (complaint + insurer's position); the label is the ombudsman's **outcome** in three classes.

## 8. Anonymisation

Personal data is removed **before** any processed text is written. Method: Presidio NER + source-specific regexes + the name list from each award header. Spec: [`docs/data/anonymisation-spec.md`](docs/data/anonymisation-spec.md).

| Replaced with | What |
|---|---|
| `[PERSON]` | Complainant and family names |
| `[ADDRESS]` | Addresses, PIN codes, places below state level |
| `[CONTACT]` | Phone numbers, emails |
| `[REF]` | Policy, claim, award and complaint numbers |
| `[PROVIDER]` | Hospital and doctor names |
| `[EMPLOYER]` | Employer names (group policies) |
| Age band / month-year | Exact ages and dates of birth; exact dates |
| **Kept** | Insurer names (public parties), medical condition, claim amounts |

`doc_id` links back to raw files only on the author's machine.

## 10. Known gaps ✍️

| Gap | Effect | Where measured |
|---|---|---|
| **Selection bias**: only disputes that reached an ombudsman and ended in a published decision | Label rates describe escalated cases, not all rejected claims; may be optimistic | Not measurable; stated |
| **Jurisdiction mismatch**: UK and Irish regulation, products and procedure differ from India's | Pooled metrics can hide weak Indian performance | India-only and cross-country tables (PR 14) |
| **Label noise** in free-text Indian awards; FOS has no partial class | Blurred `upheld` / `partially_upheld` boundary | A2 audit; error code D1 |
| **Missing offices / layouts**: unsegmentable CIOINS layouts dropped | Some offices under-represented | Funnel by office: ⟨list⟩ |
| **Small splits**: test covers about one year | Wide confidence intervals | Bootstrap CIs |
| **Anonymisation detail loss**: exact dates, providers, ages generalised | Some waiting-period and network-hospital disputes harder | Error analysis (PR 15) |
| **Source mix depends on permissions** | Balance may differ from plan | §2 above |
| ⟨any other gap found during the build⟩ | | |

## 11. Intended use ✍️

**For:** training and evaluating the ClaimSense classifier, building its precedent index, and research on how published ombudsman decisions on health-insurance disputes were decided.

**Not for:**

- legal advice or deciding whether any individual should pursue a complaint;
- decisions about individuals by insurers, employers, lenders or anyone else;
- ranking, scoring or naming insurers (escalated complaints are a skewed sample);
- re-identifying anyone in the decisions;
- redistribution of the text beyond what each source's terms allow (§2).
