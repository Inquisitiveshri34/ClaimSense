## 5. E2E tests — final whole-system check

**`tests/e2e/test_e2e_18_full_rebuild.py`** (uses a **new, separate** world, not the session one):
1. `scripts/reproduce.sh --world` from an empty world runs collect (fake sites) → parse → label → build → baselines → finetune(smoke) → calibrate → index → topic/thresholds → report, using only `make` targets and CLIs a user would run.
2. Assert the produced report's metrics equal those of the session world (same seed → same results: full determinism across the whole chain).
3. `pipeline.load()` + `predict()` on 5 world test records; Streamlit `AppTest` Predict page on one of them.
4. Every artefact's `dataset_version` matches; all leak probes pass on the rebuilt dataset; `pii_scan` 0 hits.
5. Runtime of this test < 5 minutes on CI (record it).

Then run the **entire** test suite one last time: `make pr-check` including every e2e file from PR 1 to PR 18.
