## 1. Goal

The numbers every later model must beat: B1 majority class, B2 rejection-reason rules, B3 TF-IDF + logistic regression. Also the shared `Classifier` interface, metrics module and experiment tracking that PRs 10–16 reuse.

## 2. Files to add

| File | Contents |

| `src/claimsense/models/baselines.py` | `MajorityClass`, `ReasonRules` (most common label per `rejection_reason` on train, fallback majority), `TfidfLogReg` (grid over `C_grid` on val macro-F1, `class_weight="balanced"`) |

## 4. Tests to write

- **`test_metrics.py`**: perfect predictions → F1 1.0; known small confusion matrix → hand-computed macro-F1 and PR-AUC; label order respected.
- **`test_baselines_smoke.py`** (mini dataset): each baseline fits, `predict_proba` shape `(n,3)`, rows sum to 1, save → load → same probabilities; B1 always predicts the train majority; B2 uses the reason map.
- **`test_tracking.py`**: with `MLFLOW_TRACKING_URI` in tmp, a run logs params, metrics and `dataset_version`; `export_table` renders run IDs and numbers.
- **Input-columns guard**: a classifier fitted on a DataFrame that contains `findings` or `award` columns raises (only `facts_text` + allowed metadata may be used). Add this case to `tests/leak/test_input_columns.py`.

## 5. E2E tests

`tests/e2e/e2e_config.yaml`: small `C_grid`. `stages.py`: `run_baselines(world)` (→ `run_build`).

**`tests/e2e/test_e2e_09_baselines.py`**:
- B1–B3 train on the world dataset; MLflow in the world has 3 runs each with `macro_f1`, `pr_auc`, and `dataset_version == LATEST`.
- B3 macro-F1 > B1 macro-F1 on world val (the corpus signal is learnable end to end).
- Saved baselines reload from `models_dir()` inside the world.
- `test_e2e_99_contracts.py` extended: baseline `meta.json` versions match `LATEST`.
