## 1. Goal

One command reads the dataset and every artefact and writes the honest results report: metrics with confidence intervals, breakdowns, India-only, the facts-only vs findings-included gap (leakage sanity), and cross-country generalisation.

## 2. Files to add

| File | Contents |
|---|---|
| `src/claimsense/evaluate/predictions.py` | `collect_predictions(split) -> DataFrame`: for B1–B5 (B5 from cache/val only), the LoRA classifier (+ calibrator) on the requested split; columns `doc_id, source, country, rejection_reason, insurer_type, y_true, p_upheld, p_partially_upheld, p_rejected, model` |
| `src/claimsense/evaluate/bootstrap.py` | Stratified bootstrap (`eval.bootstrap_resamples`, `bootstrap_seed`, `stratify_by`) for any metric; returns point + 95% CI |

| `src/claimsense/evaluate/__main__.py` | `python -m claimsense.evaluate report [--out DIR]` |

## 4. Tests to write

- **`test_bootstrap.py`**: CI contains the point estimate; same seed → same CI; stratification preserves per-source counts in every resample.
- **`test_report_command.py`** (mini dataset + stub classifier + tiny calibrator + tiny index): report builds; every required heading present; "too few" marking for small slices; output contains **no record text** (no string > 200 chars from the dataset); running twice → byte-identical.

## 5. E2E tests

`stages.py`: `run_report(world)` (→ baselines, finetune smoke, calibrate, index).

**`tests/e2e/test_e2e_14_report.py`**:
- `make report`-equivalent on the world finishes and writes the report inside the world.
- The report's numbers for B3 equal the MLflow metrics logged by `run_baselines` (same data, same code → same numbers: proves the report reads the real chain, not its own copy).
- Facts-only vs findings-included gap on the world is **positive and large** (the corpus findings contain the answer; facts only contain a weak signal). If the gap is ~0, the chain is leaking → test fails.
- Every model in the report shows `dataset_version == LATEST`.
- Contracts extended: report header lists the versions of dataset, adapter, calibrator and index, all consistent.
